# История изменений

Формат основан на Keep a Changelog. Версии проекта используют Semantic Versioning.

## [1.2.0] — 2026-08-15

### Добавлено

- публичный веб-режим с локальной обработкой файлов без отправки медиа на сервер;
- отдельные подсказки для мобильного, веб- и локального режимов;
- мобильное сохранение через системное меню «Поделиться»;
- импорт файлов и папок перетаскиванием из Finder;
- тесты политики приватности, импорта и сгенерированных HTML-файлов.

### Изменено

- автономный HTML теперь собирается из читаемых модулей в `src/standalone`;
- пустая мобильная галерея стала компактнее;
- документация уточняет поведение приложения на разных устройствах.

## [1.1.0] — 2026-08-13

### Добавлено

- пошаговый возврат предыдущего изменения дат или перемещения;
- перенос выбранных файлов между папками с подтверждением;
- чтение даты съёмки из EXIF вместо системного `lastModified`;
- закрытие полноэкранного просмотра кликом;
- автоматический сброс выделения после успешного сохранения;
- продуктовая документация и архитектурное описание;
- структурная проверка автономных entrypoint-файлов и регрессионные тесты.

### Изменено

- пакет переименован в `multi-photo-change-date`;
- команды разработки сделаны кроссплатформенными;
- metadata веб-оболочки приведена к названию продукта.

## [1.0.0] — 2026-08-13

- рабочая базовая версия зафиксирована коммитом `71a9f29` и тегом `v1.0`;
- пакетное изменение дат фотографий и видео;
- папки, сортировка, предпросмотр и изменение оригиналов;
- автономный запуск через `start.html`.
