# Безопасность и приватность

## Модель данных

Приложение обрабатывает файлы локально. Содержимое медиатеки не отправляется на backend проекта. Серверная оболочка отдаёт статические ресурсы и не участвует в изменении метаданных.

## Разрешения

Доступ к каталогам запрашивается через File System Access API. Браузер показывает системный диалог и ограничивает приложение выбранной пользователем областью.

## Операции с оригиналами

- перед массовой записью отображается подтверждение;
- перед переносом отображается целевая папка и количество файлов;
- совпадающее имя блокирует перенос;
- undo доступен для последних 20 операций текущей сессии.

Undo — средство быстрого исправления, а не резервная копия. Для уникальных архивов используйте отдельный backup.

## Сообщение об уязвимости

Не публикуйте приватные фотографии или пути к медиатеке в issue. Опишите формат файла, браузер, последовательность действий и используйте обезличенный воспроизводимый пример.
